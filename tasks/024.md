# 024 — GitHub Actions

Статус: не начато. Разработчик: Backend. Зависит от: 002, 023.

## Документация

- [PDR.md](../docs/PDR.md) — §9, §12, AC-22/23: GHCR и тег версии.
- [ADR-002.md](../docs/ADR-002.md) — «Пакеты, контейнер и CI»: сборка, тесты и условная публикация.

## Работа

Настроить CI: установка по lockfile, генерация контракта, типы, линтер, тесты, сборка; публикация образа в GHCR только по тегу версии при настроенных правах.

## Приёмка

Workflow не публикует образ для pull request и обычной ветки, описывает права и условие публикации по тегу версии; локальные проверки проходят; секреты не записаны в Git.

## Проверка

AC-22/23; локальная проверка команд и разбор YAML; фактическую публикацию отмечать отдельно.

## Область файлов

.github/workflows/, package.json, README.md.

Код MVP выполнять только после отдельного разрешения владельца проекта. Изменения требований сначала согласовать и внести в PDR.
