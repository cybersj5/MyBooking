# 017 — Основа интерфейса

Статус: выполнено 06.10.2026. Разработчик: Frontend. Зависит от: 002.

Зависимость 002 подтверждена слиянием в `dev`, отметкой в индексе задач ветки `dev` и отчётом в [002.md](002.md). В отдельной ветке `feature/017-web-foundation` Тестировщик сначала зафиксировал ожидаемое падение браузерных проверок, затем разработчик собрал основу интерфейса. После двух циклов замечаний о доступном состоянии переключателя темы Ревьюер одобрил изменения. Тестировщик выполнил итоговую проверку на компьютере и телефоне.

Итог на Node.js 24.14.1 и npm 11.11.0: `PLAYWRIGHT_BROWSER_CHANNEL=msedge npm run test --workspace @mybooking/e2e -- --reporter=line --workers=1` — 8 проверок прошли в Edge при ширине 1280 и 390 пикселей. Проверены переключение темы через Enter и Space, доступные имя, состояние и описание переключателя, видимый фокус, отсутствие горизонтального скролла, ошибка неизвестного маршрута, переход на главную и сохранение темы после навигации и перезагрузки. Скриншоты светлой и тёмной тем на обеих ширинах осмотрены. `npm run typecheck --workspace @mybooking/web`, `npm run typecheck --workspace @mybooking/e2e`, `npm run lint`, `npm run build` и проверка Prettier изменённых файлов завершились с кодом 0. Общая `npm run format:check` завершилась с кодом 1 из-за 20 ранее существовавших неизменённых файлов вне задачи.

Точные закреплённые версии Node.js 24.21.0 и npm 12.2.0 не были доступны; встроенный Chromium не установлен, поэтому браузерные проверки выполнены в Edge. Общий компонент загрузки создан, но не проверен в реальном пользовательском сценарии, так как он ещё не подключён к странице с загрузкой данных. Календарные виды, основные бизнес-действия и обновления второй сессии из полного AC-17 относятся к следующим задачам и здесь не проверялись. Коммиты, `git push` и публикация не выполнялись.
