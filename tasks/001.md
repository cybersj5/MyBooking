## Работа

Создать четыре workspace (`contract`, `server`, `web`, `e2e`), общий lockfile, strict TypeScript, ESLint и Prettier.

## Приёмка

`npm install` в корне ставит все пакеты; typecheck, lint и build имеют реальные скрипты.

## Проверка

AC-22; выполнить установку и базовые скрипты.

Повторная проверка 05.10.2026 в ветке `feature/001-workspace-scaffold`: Node.js 24.21.0 LTS, npm 12.2.0; `npm install`, `npm ls --workspaces --depth=0`, `npm run typecheck`, `npm run lint`, `npm run format:check` и `npm run build` завершились успешно. Полный AC-22 остаётся за задачами контракта и сервера: генерация OpenAPI и проверка входа через Zod здесь не выполнялись.
