# 008 — Расписание эксперта

Статус: выполнено 06.10.2026 в согласованной границе 008; ревью и независимая проверка пройдены. Роль: backend. Зависит от: 003, 004, 007.

## Документация

- [PDR.md](../docs/PDR.md) — TIME-01/12/13, §4.6, AC-03/10/11.
- [ADR-001.md](../docs/ADR-001.md) — «SQLite и конкурентные изменения», «Семантика времени».
- [ONTOLOGY.md](../docs/ONTOLOGY.md) — §5.3: расписание и последствия.

## Работа

Реализовать проверку и внутреннее хранение недельных интервалов и исключённых дат через общий транзакционный протокол, а также чтение собственного расписания. Проверить смену пояса через существующий маршрут профиля. Публичные preview и сохранение с последствиями выполняет задача 013.

## Приёмка

Невалидные интервалы и даты отклоняются; чтение доступно только владельцу; внутренняя замена атомарна и не меняет чужое расписание. Смена пояса не сдвигает UTC существующих записей, не меняет локальные часы и исключённые даты и не отменяет записи.

## Проверка

TIME-01/12/13, частично AC-03/11; API и SQLite тесты. Полный AC-03 зависит от задачи 009, полный AC-10 — от задачи 013.

## Область файлов

server/src/availability/, server/src/repository.ts, server/tests/, server/src/auth/index.ts только для регистрации GET и передачи проверки сессии. Последнее расширение разрешено владельцем 06.10.2026.

Код MVP выполнять только после отдельного разрешения владельца проекта. Изменения требований сначала согласовать и внести в PDR.

## Подготовка перед реализацией

Проверка 06.10.2026: задачи 003, 004 и 007 отмечены выполненными; их коммиты входят в локальный `origin/dev`. Актуальность удалённой ветки не подтверждена: `git fetch origin` завершился `Permission denied (publickey)`.

Граница 008/013 согласована владельцем 06.10.2026. Ниже распределение существующих требований; новые требования и архитектура не вводятся.

### Граница задач

| Задача | Результат | Проверка |
| --- | --- | --- |
| 008 | Проверка недельных интервалов (день 1–7, локальное время, шаг 15 минут, `startLocal < endLocal`, отсутствие наложений), исключённых календарных дат и IANA-пояса. Чтение собственного расписания через согласованный `GET /api/v1/me/availability`. Внутренняя команда замены интервалов и дат через общий `BEGIN IMMEDIATE`, доступная только серверному коду и не вызываемая из публичного HTTP до 013. Проверка принадлежности эксперту. | API-тест чтения и прав; SQLite-тест атомарной замены, отклонения неверных данных и изоляции владельцев. Без публичного сохранения AC-10 не считается пройденным. |
| 013 | Публичные `POST /api/v1/me/availability/preview` и `PUT /api/v1/me/availability` по уже согласованному контракту: версия связана с предложением и последствиями; при сохранении список пересчитывается под блокировкой; без актуальной версии или согласия изменения нет; запись расписания, закрытие затронутых записей и задачи уведомлений атомарны. | Полный AC-10, API и конкурентные SQLite-тесты. |

Причина разделения: PDR §4.6, AVAIL-01 и AC-10 требуют preview и закрытия затронутых записей. Согласованные `docs/specs/availability.md` и `contract/main.tsp` не предусматривают упрощённый публичный `PUT`. Задача 013 зависит от 011/012, которые создают и переводят заявки. Публичную запись в 008 без этих сценариев нельзя объявить соответствующей контракту. PDR и публичный контракт не меняются.

Смена пояса уже выполняется через `PUT /api/v1/me/profile` задачи 004, внутри `immediate` из `server/src/repository.ts`. Второй маршрут или команда в 008 не добавляются. В 008 проверить SQLite-инвариант: после смены пояса локальные часы и исключённые даты сохраняются, `startUtc`/`endUtc` существующих записей и их статусы остаются теми же. Если потребуется исправление кода профиля в `server/src/auth/`, сначала передать владение этим файлом задаче 008.

Актуальность `origin/dev` проверить при восстановлении доступа к удалённому репозиторию. Локальная база содержит зависимости 003/004/007.

### Результат проверки

Тестировщик сначала зафиксировал Red: GET возвращал `404` вместо ожидаемых `401`/`200`; внутренняя команда хранения отсутствовала. После реализации Ревьюер одобрил права, валидацию, общий `BEGIN IMMEDIATE` и неизменность UTC при смене пояса. Тестировщик добавил проверку отката при ошибке SQLite; Ревьюер одобрил и её.

Независимый Green: `npm run test -w server` — 14 файлов, 43 теста успешно; `npm run typecheck -w server`, `npm run build -w server`, `npm run lint`, `npx prettier --check server/tests/availability-api.test.ts server/tests/availability-storage.test.ts server/src/availability/index.ts server/src/auth/index.ts server/src/repository.ts` и `git diff --check` — успешно. Корневая `npm run format:check` завершилась с ошибкой на 40 файлах вне задачи 008; пять изменённых файлов форматирование проходят. Публичные preview/PUT и полный AC-10 не проверялись: они относятся к 013. Полный AC-03 требует расчёта слотов в 009.
