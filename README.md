# MyBooking

MyBooking — учебный сервис записи на индивидуальные встречи. Эксперт задаёт расписание и делится личной ссылкой. Гость без аккаунта видит свободные слоты, подтверждает email кодом и подаёт заявку. Эксперт подтверждает одну из пересекающихся заявок; остальным гостям предлагается выбрать другое время.

## Статус

Сейчас в репозитории только документация. Код MVP, контейнер, тесты и CI ещё не созданы. Команды установки и запуска будут добавлены после реализации и фактической проверки. Начало написания кода требует отдельного согласия владельца проекта.

## Целевой результат

Планируются npm workspace с четырьмя пакетами (`contract`, `server`, `web`, `e2e`), сгенерированный OpenAPI 3.1, работающий Docker Compose с постоянным томом SQLite и GitHub Actions для сборки, тестов и публикации образа. Телемост, SSO, расширенная админка и сам деплой отложены до следующих этапов.

Для учебного MVP предусмотрены краткие пояснения о данных и cookie. Правовая подготовка нужна только перед фактическим публичным запуском. Текущий этап не подтверждает работу SMTP, импорт ICS, сборку контейнера и сквозные сценарии.
