# Спецификация публичного HTTP-контракта `privacy`

Статус: публичная форма согласована владельцем 05.10.2026. Основание: [PDR §8.1](../PDR.md), PRIV-01–05, AC-20/21; [ADR-002 «Идентичность и право доступа»](../ADR-002.md); согласованный вход [identity](identity.md).

## Граница

`identity` уже принимает `consentVersion` и `consentAccepted: true` при запросе кода. `privacy` предоставляет публичные тексты и актуальную версию согласия. Сервер сверяет версию и фиксирует согласие при создании аккаунта или заявки по PRIV-01. Уведомление о необходимых cookie носит информационный характер.

## Публичный HTTP-контракт

| Метод и путь | Вход | Успех | Доступ |
| --- | --- | --- | --- |
| `GET /api/v1/privacy` | — | `200 {consentVersion, summary, document, deletionContact, cookieNotice}` | Публично, без сессии |

Все пять полей обязательны и имеют тип строки. Тексты — на русском языке. `document` — обычный текст краткого документа без HTML или Markdown; `deletionContact` — публичный рабочий email из конфигурации. `cookieNotice` описывает назначение, срок и удаление только необходимых cookie. Ответ не содержит серверную конфигурацию, секреты или запись чужого согласия. Необязательные cookie и API для согласия на них отсутствуют.

`consentVersion` из ответа используется в командах `identity` и создания заявки. Устаревшая версия получает `400` с публичным кодом `consent_outdated` и безопасным русским описанием. Сервер не создаёт challenge или заявку при такой ошибке.
